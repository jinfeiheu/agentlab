# RAG v1 参数存档(已废弃)

## 存档说明

本文档是 2026-03-01 至 2026-08-14 的旧配置存档。v1 已于 2026-08-15 被 v2 取代,任何生产或评测都必须使用 v2 参数。

## 切分参数(v1)

v1 使用 chunk_size=512 字符,chunk_overlap=64 字符,只按空行切分,不识别 Markdown 标题。

## 检索参数(v1)

v1 只做向量检索,top_k=5,没有 BM25,也没有 RRF 融合。候选池大小为 5。

## 嵌入模型(v1)

v1 使用 bge-small 嵌入,向量维度 512。该模型已从 Ollama 默认模型中移除。

## 迁移记录

2026-08-15 完成迁移:切分改为标题感知,嵌入升级到 bge-m3(1024 维),新增 BM25 与 RRF,默认 top_k 从 5 调整为 6。
